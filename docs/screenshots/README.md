# Screenshots

The README's screenshot section is commented out until there are images here.

If you'd like to fill it in, this is a genuinely useful contribution — a
project with no screenshots is one nobody can evaluate without cloning it.

**Use dummy data.** Task titles, comments, email addresses and avatars from a
real workspace must not be published here. Seed a local instance with invented
content instead.

Wanted, at roughly 1600px wide, light theme unless the shot is specifically
about dark mode:

| File | What it should show |
|---|---|
| `board.png` | The Kanban board with a few tasks across several columns |
| `task-detail.png` | A task with a description, a comment and an attachment |
| `dashboard.png` | The dashboard with its stat tiles and breakdowns |
| `notifications.png` | The bell popover open, with a few unread items |
| `mcp-settings.png` | Settings → MCP, with a token **revoked before the shot** |
